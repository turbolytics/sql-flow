# One owner for timestamp text Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Arrow value that becomes text goes through `internal/arrowfmt`, so a dependency upgrade cannot change a timestamp string.

**Architecture:** A new package renders Arrow values to JSON and text. A timestamp renders as a UTC instant in `time.RFC3339Nano`. A container holding a timestamp is rebuilt by the package. Every other value passes through to Arrow. Five call sites move to it, and a guard test blocks new direct calls.

**Tech Stack:** Go 1.27.3, `github.com/apache/arrow-go/v18`, `github.com/zeebo/assert`.

**Spec:** `docs/superpowers/specs/2026-11-01-arrowfmt-design.md`

## Global Constraints

- A timestamp renders as `toTime(v).Format(time.RFC3339Nano)`, where `toTime` is `(*arrow.TimestampType).GetToTimeFunc()`. A zone-less type gives UTC, so the text ends in `Z`. A zoned type gives the column's zone, so the text ends in an offset. This is arrow-go 18.7.0's rendering, byte for byte.
- A type tree with no timestamp renders exactly as Arrow does today.
- Prose follows the repo's CLAUDE.md: SQLFlow in prose, `sqlflow` for the command.
- Go struct literals put each field on its own line.
- Tests use `github.com/zeebo/assert` and `coverage.Covers(t, "<id>")` where the file already does.
- Run go, make, docker and gh outside the sandbox. Set `GOPATH=$HOME/.cache/gopath-go127` and `GOFLAGS=-modcacherw` for go.
- Push with `git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push`. The keychain token lacks the `workflow` scope.
- Open the PR against `main`. Write bodies to a file made with `mktemp`, and read the PR back.
- Run only the tests a task names. CI runs the rest.

## Review Focus

1. A timestamp outside years 0 to 9999 must not error or panic. Pinned in Task 1.
2. A null timestamp inside a list, a struct field and a map value must render `null`. Pinned in Task 1.
3. A zoned timestamp must render the same instant as the same value without a zone, in the column's zone. Pinned in Task 1.
4. A dictionary-encoded column holding timestamps must render each value, not its index. Pinned in Task 1.
5. A list of structs holding a timestamp, two levels deep, must render every timestamp. Pinned in Task 1.

### Task 1: The arrowfmt package

**Files:**
- Create: `internal/arrowfmt/arrowfmt.go`
- Test: `internal/arrowfmt/arrowfmt_test.go`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `func Marshal(col arrow.Array, i int) ([]byte, error)`: JSON for element `i`.
  - `func Value(col arrow.Array, i int) any`: the value `json.Marshal` renders. Arrow's `GetOneForMarshal` shape, with timestamps replaced by strings.
  - `func Text(col arrow.Array, i int) string`: the replacement for `ValueStr`.
  - `func RecordRow(rec arrow.RecordBatch, i int) ([]byte, error)`: one JSON object per row, the same bytes `array.RecordToJSON` writes for a record with no timestamp.

```go

func TestArrowfmtTimestamp_ZonedRendersInItsOwnZone(t *testing.T) // Asia/Tokyo us: same instant as naive us, +09:00 offset
```

Assertions:
- Zoned `Asia/Tokyo` us: `"2026-09-08T21:00:00.123456+09:00"`.
- ns: `"2026-09-08T12:00:00.123456789Z"`. us: `"2026-09-08T12:00:00.123456Z"`. ms: `"2026-09-08T12:00:00.123Z"`. s: `"2026-09-08T12:00:00Z"`.
- `list<timestamp[ms]>` of three: `["2026-09-08T12:00:00.123Z","2026-09-08T12:00:00.123Z","2026-09-08T12:00:00.123Z"]`.
- The out-of-range cases return no error and a non-empty string.
- `TypesWithoutATimestampMatchArrow` is a table over int64, float64, string, bool, decimal128, date32, time64, binary, `list<int64>`, `struct<a int64>` and `map<string,int64>`. For each, `Marshal` equals `json.Marshal(col.GetOneForMarshal(i))`.
- `RecordRow` equals each line of `array.RecordToJSON` for a record with three non-timestamp columns, including key order.

- [ ] **Step 3: Run the tests to verify they fail**

- [ ] **Step 4: Implement the four functions in `internal/arrowfmt/arrowfmt.go`**

`Value` returns `GetOneForMarshal` when the column's type tree has no timestamp. A helper `containsTimestamp(arrow.DataType) bool` decides, and walks list, large list, fixed-size list, struct, map and dictionary value types. Otherwise `Value` rebuilds the container: list kinds give `[]any`, a struct gives `map[string]any`, a map keeps the shape Arrow's `GetOneForMarshal` gives, and a dictionary renders the value at its index. A timestamp gives the Global Constraints rendering, or `nil` when null. `Text` renders a timestamp the same way and delegates the rest to `ValueStr`. `RecordRow` builds a `map[string]any` of column name to `Value` and calls `json.Marshal`.
